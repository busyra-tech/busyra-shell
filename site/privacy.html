Kebijakan Privasi

Terakhir diperbarui: 19 November 2026

Djie Shell adalah aplikasi SSH client untuk macOS dan Windows. Kebijakan ini menjelaskan data apa yang diproses aplikasi dan bagaimana data itu dilindungi.

Data yang disimpan

Daftar host, username, password, SSH key, dan pengaturan lain disimpan di perangkatmu dalam satu file vault yang dienkripsi dengan master password (Argon2id + XChaCha20-Poly1305). Master password tidak pernah disimpan atau dikirim ke mana pun.

Login dengan Google

Jika kamu memilih “Masuk dengan Google”, aplikasi meminta izin berikut:

  • openid dan email — untuk mengetahui alamat email akunmu dan menampilkannya di aplikasi.
  • drive.appdata — untuk menyimpan salinan vault terenkripsi di folder data aplikasi tersembunyi di Google Drive milikmu sendiri, agar bisa disinkronkan antar perangkat. Izin ini tidak memberi akses ke file lain di Google Drive-mu.

Data yang disimpan di Google Drive selalu dalam bentuk terenkripsi. Tanpa master password, isinya tidak bisa dibaca oleh siapa pun, termasuk pengembang dan Google.

Yang tidak kami lakukan

  • Tidak ada server Djie Shell: data tidak pernah dikirim ke server pengembang.
  • Tidak ada analitik, iklan, atau pelacakan.
  • Data dari layanan Google tidak dijual, tidak dibagikan ke pihak ketiga, dan tidak dipakai untuk melatih model AI.

Penggunaan data yang diterima dari Google API mematuhi Google API Services User Data Policy, termasuk ketentuan Limited Use.

Menghapus data

Hapus aplikasi dan folder ~/Library/Application Support/Djie Shell (macOS) untuk menghapus data lokal. Untuk menghapus data di Google Drive dan mencabut izin, buka myaccount.google.com/permissions, pilih Djie Shell, lalu hapus aksesnya.
