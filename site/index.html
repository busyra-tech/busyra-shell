Install

macOS

  1. Download file .dmg, buka, lalu seret Djie Shell ke folder Applications.
  2. Saat pertama dibuka muncul peringatan "tidak dapat diverifikasi". Buka System Settings → Privacy & Security, lalu klik Open Anyway.
  3. Atau lewat Terminal: xattr -cr "/Applications/Djie Shell.app"

Windows

  1. Download file -setup.exe atau .msi, lalu jalankan.
  2. Jika muncul "Windows protected your PC", klik More info → Run anyway.

App belum ditandatangani sertifikat developer berbayar, jadi peringatan di atas normal. Kode sumber terbuka di GitHub.
